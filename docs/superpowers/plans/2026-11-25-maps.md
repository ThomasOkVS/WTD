## The maps (logical 1280×720; HUD rules as today)

Each map: `{ id, name, blurb, difficulty: 'Easy'|'Medium'|'Hard', PATH, GRAND_CRU, CANDLES, BARRELS, floorTint? }`.

| id | Name | Layout idea | Feel |
|---|---|---|---|
| `cellar` | The Cellar | Today's S-bend, moved unchanged from `map.js`. | Medium (default) |
| `tasting-room` | The Tasting Room | A long double loop around a central "tasting table" island. The path enters top-left, circles a big central rectangle twice (outer then inner lane), and ends centre. Long path, lots of build space in the middle. | Easy |
| `catacombs` | The Catacombs | A tight zig-zag of 5 short vertical legs from left to right, with the Grand Cru at the far right. A shorter path with pinch points near the HUD. | Hard |

Rules every map must satisfy (unit-tested):
- the path starts off-screen (x < 0 or y < 0)
- every vertex is inside x −40..1320, y 60..590
- `GRAND_CRU` equals the last vertex
- candles and barrels are ≥ `PATH_CLEARANCE` from the path and inside the playfield
- there are at least 60 valid build spots on the 8 px grid
- path length is 2000–4200 px (today's is about 3200).

Stay on the 1280×720 world and the existing `HUD_ZONES`.
